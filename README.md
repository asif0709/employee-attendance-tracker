# Employee Attendance Tracker

A Java and MySQL application focused on managing employee attendance records and practising database-driven application development.

## What I worked on

- Employee attendance record management
- CRUD operations for employee data
- MySQL database integration
- SQL joins and structured queries
- Database normalization
- Indexing for organised data access
- Exception handling and application logic

## Tech Stack

- Java
- SQL
- MySQL

## Project focus

I built this project to strengthen my understanding of Java application development together with relational database design and SQL.
